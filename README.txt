Expense Tracker (installable web app)

Put these files in one GitHub repository and turn on GitHub Pages:
1. github.com > New repository (for example: expense-tracker), set it to Public.
2. Upload all files from this folder: index.html, manifest.json, sw.js, icon.svg, icon-192.png, icon-512.png.
3. Repository Settings > Pages > Source: "Deploy from a branch", Branch: main, Folder: / (root) > Save.
4. After a minute, open https://YOUR-USERNAME.github.io/expense-tracker/ on any phone or laptop.
5. Install it: Chrome/Edge show an Install icon (laptop) or "Add to Home screen" / "Install app" (Android). On iPhone use Safari > Share > Add to Home Screen.

It works offline after the first visit. Data is stored on each device.
